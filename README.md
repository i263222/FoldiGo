## Overview
This repository contains the multi-page website for **FoldiGo** — a foldable shopping bag that folds into a compact keychain. Built using pure **HTML5, CSS3, and JavaScript**.

## Project Files
- `index.html`: Home page featuring product introduction, features list, and price table.
- `how-it-works.html`: 4-step folding guide and demo button.
- `about.html`: Brand story and eco-mission details.
- `contact.html`: Product order form with console logging and JavaScript alerts.
- `style.css`: Unified stylesheet (Pink theme, Blanchedalmond buttons, oblique styling).
- `prompts.docx`: Log of AI prompts, code fixes, and screenshots.
- `bag.jpg` / `images.jpg`: Product images.

## Features
- Consistent Header Navigation bar (`<nav>`) and Footer across all pages.
- Dynamic JavaScript events using `alert()` and `console.log()`.
